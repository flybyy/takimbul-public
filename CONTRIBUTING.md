# Contributing

TakımBul kaynak kodu public olarak görüntülenebilir ancak proje **All Rights Reserved** lisansı altındadır.

Hata bildirimi veya geliştirme önerisi göndermek istersen önce bir GitHub Issue açabilirsin. Kod katkıları proje sahibinin ön onayı olmadan lisans hakkı veya yeniden kullanım izni oluşturmaz.

Katkı gönderirken:

1. Gerçek kullanıcı verisi ekleme.
2. Secret / API key / production config commit etme.
3. Mevcut testleri bozma.
4. UI değişikliklerinde mobil görünümü kontrol et.
5. Güvenlik sorunlarını public issue yerine `SECURITY.md` akışına göre bildir.
