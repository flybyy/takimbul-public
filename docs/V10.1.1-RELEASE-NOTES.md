# TakımBul v10.1.1 — Production Repair & Launch Audit

Bu sürüm, canlı ortamda kayıt sırasında görülen “Kayıt şu anda tamamlanamadı” ve bazı sayfalardaki genel 500 ekranlarının kök nedeni olan eksik/yarım veritabanı upgrade zincirini güvenli biçimde onarmak için hazırlanmıştır.

## Ne değişti?

- `app/Core/SchemaRepair.php`: Güncel `database/schema.sql` dosyasını source-of-truth olarak okuyup canlı veritabanını tablo, kolon, index ve kritik ENUM seviyesinde denetler.
- `scripts/production-repair.php`: Varsayılan olarak yalnız audit yapar. `--apply` verilmeden veritabanını değiştirmez.
- `scripts/production-smoke.php`: Canlı DB'de kritik modülleri okur; kayıt/profil/müsaitlik/amatör ilan/reklam yazma akışını transaction içinde test eder ve tüm test verisini rollback eder.
- `scripts/launch-check.php`: Repair audit ile aynı şema kaynağını kullanır ve DB runtime şeması eksikse kritik hata döndürür.
- 500 hatalarında güvenli `TB-...` destek kodu gösterilir; log satırı istek yolu, HTTP metodu ve oturum tipini içerir.
- Kayıt PDO hatalarında aynı güvenli hata kodu kullanıcıya gösterilir.

## Veri güvenliği

Production repair içinde `DROP`, `TRUNCATE` veya kullanıcı/takım/maç/reklam verisini topluca silen komut yoktur. Eksik tablolar `CREATE TABLE IF NOT EXISTS` mantığıyla, eksik kolon ve indexler yalnız güvenli ise eklenir. Mevcut `veribayt` admin parolası resetlenmez; admin yoksa yalnız hash ile seed edilir. Eski public admin satırı varsa ayrı admin mimarisine uygun tombstone kaydına çevrilir.

## Canlı onarım sırası

```bash
php scripts/production-repair.php
php scripts/production-repair.php --apply
php scripts/launch-check.php
php scripts/production-smoke.php
```

Dört komut da hata vermeden tamamlanmadan gerçek kullanıcı kayıtları açılmamalıdır.

## Veritabanı notu

Bu sürüm için ayrıca manuel migration zinciri çalıştırmak gerekmez; production repair mevcut kısmi v9/v10/v10.1 şemasını güncel v10.1 şema sözleşmesine tamamlar. `database/schema.sql` boş veritabanı içindir ve canlı dolu DB'ye manuel import edilmemelidir.
