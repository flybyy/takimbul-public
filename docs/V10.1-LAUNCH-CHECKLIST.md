# TakımBul V10.1 — Canlı Açılış Checklist

V10 kurulumunun üstüne geçiş içindir. Kullanıcı veritabanını sıfırlamayın.

## 1. Yedek

- Mevcut veritabanının tam SQL yedeğini alın.
- Canlı `config/app.php` dosyasını yedekleyin.
- `public/uploads/` klasörünü koruyun.

## 2. Dosyalar

- V10.1 dosyalarını V10 dosyalarının üstüne yükleyin.
- ZIP içindeki örnek yapı canlı `config/app.php` dosyasını içermez; mevcut config korunmalıdır.
- `public/uploads/` içindeki kullanıcı dosyalarını silmeyin.

## 3. Migration

Mevcut V10 veritabanında yalnızca bir kez çalıştırın:

```text
database/migrations/2026-09-02-v101-amateur-player-market.sql
```

`database/schema.sql` çalıştırmayın; bu dosya yalnız sıfır kurulum içindir.

## 4. Launch check

Sunucuda proje kökünde:

```bash
php scripts/launch-check.php
```

Kritik `[!!]` satırlarını giderin. Özellikle `pdo_mysql`, DB bağlantısı, v10.1 tabloları ve reklam slotları kontrol edilmelidir.

## 5. Gerçek kullanıcı testi

Bir normal oyuncu hesabıyla:

1. `/amator-ilanim` açın.
2. Temel ilan bilgilerini doldurun.
3. En az iki geçmiş kulüp/sezon satırı ekleyin; maç, ilk 11, gol ve asist verisi girin.
4. Taslak kaydedin.
5. Moderasyona gönderin.
6. Admin hesabıyla `/admin/amator-ilanlar` üzerinden ilanı onaylayın.
7. `/amator-futbolcular` listesinde ilanı bulun.
8. `/amator-futbolcu/{slug}` detayında geçmiş kulüpleri ve öz-beyan etiketini kontrol edin.
9. İkinci kullanıcıyla favori ve mesaj akışını deneyin.
10. Takım yöneticisi hesabıyla `Takıma Davet Et` akışını deneyin.
11. İlan sahibi `Takımımı Buldum` işlemini test etsin.

## 6. Gizlilik

- Telefon numarası liste kartında görünmemeli.
- İlan detayında telefon düz metin olarak görünmemeli.
- WhatsApp yalnız açık izin varsa görünmeli.
- 18 yaş altı ilanda WhatsApp public bağlantısı üretilmemeli.
- Öz-beyan geçmiş, `TakımBul Doğrulanmış` istatistiklerinden ayrı görünmeli.

## 7. Reklam

Admin Reklam Merkezi'nde en az bir test kampanyasıyla:

- `amateur_list_top`
- `amateur_list_inline`
- `amateur_detail_inline`

slotlarını kontrol edin. Gösterim/tıklama ve il/ilçe hedefleme doğrulanmalıdır.

## 8. SEO

- `/amator-futbolcular` HTTP 200
- aktif ilan detay URL'si HTTP 200
- `/sitemap.xml` HTTP 200 ve aktif ilan URL'sini içermeli
- `/robots.txt` HTTP 200
- `/amator-ilanim` noindex
- public ilan detail canonical/OG/JSON-LD mevcut

## 9. Son kontrol

- Masaüstü + mobil filtre görünümü
- Kariyer geçmişi tablo yatay taşma davranışı
- Formda en fazla 12 geçmiş kulüp satırı
- Yanlış CSRF isteği 419
- Yetkisiz admin erişimi engelli
- PHP error log'da fatal/PDO hata yok
