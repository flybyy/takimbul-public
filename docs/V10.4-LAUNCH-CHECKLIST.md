# TakımBul V10.4 — Canlıya Çıkış Checklisti

## 1. Yedek
- Canlı veritabanının tam yedeğini al.
- `config/app.php` dosyasını yedekle.
- `public/uploads/` klasörünü yedekle.

## 2. Dosyaları yükle
V10.4 production ZIP içeriğini uygulama köküne yükle.

**Üzerine yazma / silme:**
- `config/app.php`
- canlı `public/uploads/` içeriği

## 3. PHP gereksinimini doğrula
Sunucuda en az PHP 8.1 ve `pdo_mysql` aktif olmalı.

```bash
php -v
php -m | grep -i pdo_mysql
```

## 4. Production repair dry-run
```bash
php scripts/production-repair.php
```

Çıktıyı kontrol et. Script veri silen DROP/TRUNCATE işlemi yapmamalıdır.

## 5. Eksik şemayı uygula
```bash
php scripts/production-repair.php --apply
```

Bu adım V10.4 `news` tablosu dahil eksik runtime şemasını güvenli şekilde tamamlar.

## 6. Launch gate
```bash
php scripts/launch-check.php
```

V10.4 konum verisi, news migration/routes, favicon ve canlı DB `news` tablosu dahil kontroller PASS olmalı.

## 7. Transactional production smoke
```bash
php scripts/production-smoke.php
```

Smoke geçici kullanıcı/profil/müsaitlik/vitrin/reklam/haber verileri oluşturur ve transaction sonunda rollback eder.

## 8. Browser QA
Sunucuda Chromium/Playwright koşulları uygunsa:

```bash
bash tests/v103_browser_smoke.sh
```

Kritik sayfalar 320 / 360 / 390 / 430 / 1440 px genişliklerde yatay taşma ve JS/page error olmadan render edilmelidir.

## 9. Gerçek kullanıcı kabul testi
1. `/uye-ol` aç.
2. Ad, kullanıcı adı, telefon, e-posta gir.
3. Şifreyi iki kez gir.
4. `Antalya` seç ve ilçelerde `Alanya` geldiğini doğrula.
5. Hesabı oluştur.
6. `/baslangic` onboarding ekranına geldiğini doğrula.
7. Profili düzenle ve konumun kaydedildiğini doğrula.
8. Çıkış yap ve tekrar giriş yap.
9. Oyuncu vitrini / takım arama akışını dene.
10. İkinci kullanıcıyla mesaj ve bildirim akışını kontrol et.

## 10. Haber kabul testi
1. `/admin/giris` ile admin oturumu aç.
2. `/admin/haberler` → Yeni Haber.
3. Önce taslak kaydet; public `/haberler` sayfasında görünmediğini doğrula.
4. Haberi yayınla.
5. `/haberler` sayfasında kartı gör.
6. Haber detayına gir; başlık, kategori, kapak (varsa), tarih ve görüntülenme sayısını kontrol et.
7. Sayfa kaynağında canonical/OpenGraph meta bilgilerinin bulunduğunu doğrula.

## 11. Konum kabul testi
Aşağıdaki yüzeylerden birkaçını gerçek tarayıcıda kontrol et:
- Kayıt
- Profil düzenleme
- Takım oluşturma
- `/oyuncu-bul`
- `/rakip-bul`
- `/musait-oyuncular`
- `/amator-futbolcular`
- admin reklam hedefleme

İl değiştiğinde ilçe listesinin de değiştiğini doğrula.

## 12. Reklam açmadan önce son gate
Aşağıdakilerin hepsi başarılı olmadan Meta/Instagram/Google reklamını başlatma:
- production-repair PASS
- launch-check PASS
- production-smoke PASS
- gerçek kayıt + çıkış + tekrar giriş PASS
- oyuncu profil/vitrin PASS
- admin haber yayınlama PASS
- mobil 360/390 px görsel kontrol PASS
- masaüstü 1440 px header/filter kontrol PASS

## Rollback
Beklenmeyen production problemi çıkarsa yeni dosyaları önceki release ile geri al ve DB yedeğini yalnız veri bütünlüğü gerçekten bozulduysa geri yükle. `production-repair` normal koşulda mevcut verileri silmez.
