# TakımBul V10.3 Final Launch — Release Notes

V10.3, V10.2 Oyuncu Vitrini davranışını değiştirmeden reklam trafiği öncesi son production hardening sürümüdür.

## Öne çıkanlar
- 320–430px telefonlar ve masaüstü için ek taşma/yerleşim korumaları.
- Klavye odak halkaları, dokunmatik hedefler ve uzun metin wrap güvenliği.
- Kayıt/giriş/şifre sıfırlamada şifre göster-gizle ve çift gönderim koruması.
- Eksik olan gerçek 429 hata ekranı; 403/404/419/500 görsel bütünlüğü.
- Reklam slotlarında sponsor semantiği, medya oranı ve dış reklam overflow izolasyonu.
- Oyuncu vitrini kart/detail ekranlarında uzun isim/kulüp/aksiyon satırı mobil dayanıklılığı.
- Chromium tabanlı otomatik browser smoke: 360, 430 ve 1440 px.

## Veritabanı
Yeni migration yoktur. V10.2 migrationı (`2026-09-04-v102-player-showcase.sql`) uygulanmış olmalıdır.

## Güncelleme
Canlı dosyaları yedekleyin. `config/app.php` ve `public/uploads/` klasörünü koruyun. Dosyaları güncelledikten sonra:

```bash
php scripts/production-repair.php
php scripts/production-repair.php --apply
php scripts/launch-check.php
php scripts/production-smoke.php
bash tests/v103_browser_smoke.sh
```
