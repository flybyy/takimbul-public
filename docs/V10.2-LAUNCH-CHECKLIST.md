# TakımBul.com.tr — V10.2 Canlıya Geçiş Kontrol Listesi

Bu sürüm gerçek kullanıcı açılışından önce **production veritabanında** repair, launch-check ve transactional smoke testinden geçirilmelidir.

## 1. Yedek ve korunacak dosyalar

- Veritabanının tam yedeğini alın.
- Sunucudaki gerçek `config/app.php` dosyasını koruyun; ZIP içindeki `config/app.example.php` ile değiştirmeyin.
- `public/uploads/` içindeki kullanıcı dosyalarını koruyun.
- Mevcut `storage/` log ve çalışma izinlerini koruyun.

## 2. Dosyaları yükleyin

V10.2 paketini mevcut uygulama dosyalarının üstüne yükleyin. `config/app.php` ve kullanıcı upload klasörlerini silmeyin.

## 3. Production şema denetimi ve güvenli onarım

Önce yalnızca rapor alın:

```bash
php scripts/production-repair.php
```

Rapor beklenen eksik kolon/tablo değişikliklerini gösteriyorsa uygulatın:

```bash
php scripts/production-repair.php --apply
```

V10.2 için manuel SQL deployment kullanıyorsanız alternatif olarak `database/migrations/2026-09-04-v102-player-showcase.sql` çalıştırılabilir. Migration idempotenttir; yine de production değişikliğinden önce DB yedeği zorunludur.

## 4. Launch gate

```bash
php scripts/launch-check.php
```

`FAIL` kalmamalıdır. Özellikle `amateur_player_ads.profile_intent`, V10.2 migration dosyası, auth/session dosyaları ve kritik tabloların geçtiğini kontrol edin.

## 5. Transactional production smoke

```bash
php scripts/production-smoke.php
```

Smoke test veritabanına geçici kayıt yazar ve rollback eder. PASS olmadan gerçek üyelikleri açmayın.

## 6. Gerçek tarayıcı kabul testi

Canlı domain üzerinde aşağıdaki akışları gerçek bir test hesabıyla tamamlayın:

1. `/uye-ol` ile yeni kullanıcı oluşturun.
2. Çıkış yapıp `/giris` üzerinden aynı hesapla tekrar giriş yapın.
3. `/hesabim` ve profil düzenleme sayfalarının açıldığını doğrulayın.
4. `/amator-ilanim` içinde **Kendimi tanıtıyorum** seçin; hedef lig seçmeden kaydedip moderasyona gönderin.
5. Admin panelinden profili onaylayın; `/amator-futbolcular` ve profil detayında **OYUNCU VİTRİNİ** olarak göründüğünü kontrol edin.
6. Vitrin profilinde takım daveti panelinin görünmediğini ve doğrudan endpoint isteğinin de reddedildiğini doğrulayın.
7. Profili **İkisi de** yapın; takım daveti akışını test edin.
8. `Takımımı Buldum` işlemini çalıştırın; transferin kapandığını ama profilin vitrinde kalmaya devam ettiğini doğrulayın.
9. Oyuncuya TakımBul mesajı gönderme, favorileme ve profil bildirme akışlarını kontrol edin.
10. Admin oyuncu profilleri ekranında `profile_intent` filtresi ve detay bilgisini kontrol edin.

## Yayına açma kararı

Gerçek kullanıcı kaydını yalnızca şu üç koşul birlikte sağlandığında açın:

- `production-repair.php --apply` sonrasında şema temiz,
- `launch-check.php` tamamen PASS,
- `production-smoke.php` PASS ve tarayıcıdaki gerçek kayıt → çıkış → giriş kabul testi başarılı.
