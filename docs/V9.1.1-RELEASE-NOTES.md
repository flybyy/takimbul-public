# TakımBul V9.1.1 — Launch Stable

## Amaç

V9.1'de yönetici hesabı normal kullanıcıdan ayrıldıktan sonra iki eski `Auth::isAdmin()` çağrısı kalmıştı. Bunlardan ortak kullanıcı headerındaki çağrı, başarılı girişten sonra render edilen hemen her kullanıcı sayfasında production 500 ekranına yol açabiliyordu. İkinci çağrı özel kariyer profilinde aynı riski taşıyordu.

## Düzeltilen kritik hatalar

- Normal kullanıcı headerından kaldırılmış `Auth::isAdmin()` çağrısı tamamen kaldırıldı.
- Normal kullanıcı hiçbir koşulda headerda yönetim bağlantısı görmez.
- Kariyer gizlilik/moderasyon kontrolü ayrı `AdminAuth` oturumunu kullanır.
- `veribayt` yönetici hesabı `/admin/giris` altında ayrı kalır; normal `/giris` yalnız oyuncu kullanıcıları içindir.
- Giriş yapılmış kullanıcı headerı için gerçek runtime regresyon testi eklendi.
- Gerçek HTTP oturum çerezi ile giriş yapılmış ana sayfa 200 smoke testi eklendi.

## Launch preflight

`scripts/launch-check.php` genişletildi. Canlı sunucuda artık şunları doğrular:

- PHP 8.1+ ve `pdo_mysql`
- production config / HTTPS / debug kapalı durumu
- kaldırılmış `Auth::isAdmin()` çağrılarının geri gelmemesi
- DB bağlantısı
- `users`, `player_profiles`, `teams`, `matches`, `ads`, `admins`, `site_settings`, `player_availabilities`, `availability_invites`, `match_attendance`, `player_videos` tabloları
- v9/v9.1 için zorunlu kolonlar
- ayrı `veribayt` admin kaydının aktif olması
- e-posta doğrulamasının geçici launch ayarı

## Veritabanı

V9.1.1 için yeni migration yoktur. Mevcut kurulumda `2026-09-01-v91-home-ads-admin.sql` daha önce başarıyla çalıştıysa tekrar schema import etmeyin ve veritabanını sıfırlamayın.

## Canlıya çıkış sırası

1. Mevcut `config/app.php` dosyasını koruyarak V9.1.1 dosyalarını yükleyin.
2. `php scripts/launch-check.php` çalıştırın; kritik `[!!]` satırı bırakmayın.
3. Normal kullanıcıyla kayıt → otomatik giriş → ana sayfa → profil düzenle → çıkış → tekrar giriş akışını kontrol edin.
4. Ayrı `/admin/giris` ile yönetici oturumunu kontrol edin.
5. `storage/logs` altında yeni fatal kayıt oluşmadığını doğrulayın.
