# TakımBul V10.8 Football Identities — Canlıya Çıkış Checklisti

1. Canlı `config/app.php` dosyasını ve mevcut `public/uploads` içeriğini koru.
2. Release paketindeki dosyaları yükle; özellikle `public/assets/css/app-v108.css` dosyasını atlama.
3. Sunucuda sırasıyla çalıştır:
   ```bash
   php scripts/production-repair.php
   php scripts/production-repair.php --apply
   php scripts/production-repair.php
   php scripts/launch-check.php
   php scripts/production-smoke.php
   ```
4. `launch-check` içinde `V10.8 football identities migration` ve `V10.8 football identities asset senkronu` maddelerinin OK olduğunu doğrula.
5. Gerçek kabul testi:
   - yalnız Hakem kimliğiyle yeni hesap aç; halı saha oyuncu listesinde görünmediğini doğrula,
   - hakem profilini oluştur ve moderasyona gönder,
   - Yetkili hesabıyla onayla ve lisansı ayrıca doğrula,
   - public `/hakem/{slug}` sayfasında telefon/e-posta bulunmadığını doğrula,
   - aynı kullanıcıya Teknik Direktör kimliği ekle; hakem kimliğinin kaybolmadığını doğrula,
   - teknik direktörü iki ayrı takımın teknik ekibine ekle; oyuncu kadrolarının değişmediğini doğrula,
   - bir maça hakem daveti gönderip kabul ettir.
6. 320 / 360 / 390 / 430 / 768 / 1024 / 1440 / 1920 genişliklerinde kayıt, hakem, teknik direktör ve admin kimlik ekranlarını kontrol et.
