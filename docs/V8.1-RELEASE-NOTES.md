# TakımBul v8.1 — Professional Stabilization

## Öne çıkan değişiklikler

- Giriş artık e-posta **veya kullanıcı adı** kabul eder.
- Yönetici kimliği `veribayt` / `admin@takimbul.com.tr` olarak hazırlanır; parola kaynak kodda düz metin tutulmaz.
- `/admin` gerçek operasyon dashboard'una dönüştürüldü.
- `/admin/kullanicilar` kullanıcı arama, durum kontrolü ve askıya alma/aktifleştirme ekranıdır.
- Profil düzenleme ekranına görünen ad, kullanıcı adı, il/ilçe ve güvenli avatar yükleme eklendi.
- Kariyer profili `public / members / private` görünürlüklerini gerçek erişim kuralı olarak uygular.
- Ana sayfa giriş yapan kullanıcı için gerçek maç/gol/asist/sezon puanı/MVP bilgisini gösterir.
- Ana sayfa reklam slotları giriş yapan kullanıcının il/ilçe bilgisini kullanır.
- Reklam Merkezi'ne teslimat teşhisi ve gösterim sayacını artırmayan canlı önizleme eklendi.

## Mevcut v8 kurulumu güncelleme

1. Site dosyaları ve MySQL veritabanının yedeğini alın.
2. Mevcut `config/app.php` dosyanızı koruyun.
3. v8.1 paket dosyalarını proje üzerine yükleyin.
4. `database/migrations/2026-08-31-v81-professional-stabilization.sql` dosyasını **yalnızca bir kez** çalıştırın.
5. `public/uploads/avatars` klasörünün PHP/web kullanıcısı tarafından yazılabilir olduğunu doğrulayın; `777` kullanmayın.
6. `php scripts/launch-check.php` çalıştırın.
7. Yönetici kullanıcı adıyla giriş yapıp `/admin`, `/admin/kullanicilar`, `/admin/reklamlar`, `/profil/duzenle` alanlarını kontrol edin.

## Yeni kurulum

Yeni ve boş veritabanında yalnızca güncel `database/schema.sql` dosyasını içe aktarın. Eski migration dosyalarını ayrıca çalıştırmayın.

`config/app.example.php` dosyasını `config/app.php` olarak kopyalayıp canlı veritabanı, URL, mail ve SEO bilgilerini doldurun.

## Yönetici parolası yenileme

Kaynak dosyaya parola yazmadan yönetici hesabını güvenli şekilde güncellemek için sunucunun CLI ortamında `TAKIMBUL_ADMIN_PASSWORD` değişkenini tanımlayın ve:

```bash
php scripts/admin-bootstrap.php
```

komutunu çalıştırın. Script `veribayt` hesabını aktif yönetici olarak günceller ve e-posta doğrulamasını hazırlar.
