# TakımBul V9.1.2 — Canlı Açılış Kontrol Listesi

Bu liste tamamlanmadan gerçek kullanıcı kayıtlarını açmayın.

## 1. Dosya ve SSL

- `https://takimbul.com.tr` geçerli SSL ile açılıyor.
- `http://` ve `www` tek canonical HTTPS domaine 301 yönleniyor.
- `/assets/css/app.css` HTTP 200.
- `/assets/js/app.js` HTTP 200.
- DirectAdmin tek klasör kullanılıyorsa kök `.htaccess` mevcut ve private dizinler webden kapalı.

## 2. Config ve PHP

- `config/app.php` mevcut, `env=production`, `debug=false`.
- PHP 8.1+ ve `pdo_mysql` aktif.
- `storage/logs` ve `public/uploads/avatars` yazılabilir.
- `php scripts/launch-check.php` çıkış kodu 0 ve kritik `[!!]` yok.

## 3. Veritabanı

- Mevcut DB sıfırlanmamış.
- V9.1 migrationı gerektiğinde yalnızca bir kez çalıştırılmış.
- `admins`, `users`, `player_profiles`, reklam, mesaj, maç, v9 müsaitlik/matchday tabloları launch-check'te eksiksiz.
- `veribayt` ayrı admin hesabı aktif.
- E-posta doğrulaması şimdilik kapalı.

## 4. Kullanıcı smoke testi

Gerçek bir test hesabıyla sırayla:

- `/uye-ol` → kayıt başarılı.
- Kayıt sonrası `/profil/duzenle` açılıyor.
- Profil düzenleme kaydoluyor.
- Çıkış başarılı.
- `/giris` ile tekrar giriş başarılı.
- `/musaitim`, `/musait-oyuncular`, `/rakip-bul/anlik` açılıyor.
- `/maclar`, `/mesajlar`, `/bildirimler` açılıyor.
- Kariyer profili açılıyor.

## 5. Admin smoke testi

- `/admin/giris` yalnız ayrı admin hesabını kabul ediyor.
- Normal oyuncu hesabı admin paneline giremiyor.
- `/admin`, `/admin/kullanicilar`, `/admin/reklamlar`, `/admin/ayarlar` açılıyor.
- Reklam teslimat testinde masaüstü/mobil + il/ilçe senaryoları doğru sonuç veriyor.

## 6. HTTP ve SEO

- `/robots.txt` HTTP 200.
- `/sitemap.xml` HTTP 200.
- Rastgele olmayan URL gerçek HTTP 404 ve TakımBul 404 ekranı döndürüyor.
- Yetkisiz işlem HTTP 403.
- Süresi geçmiş/yanlış CSRF HTTP 419.
- Private/işlemsel sayfalar `noindex`.

## 7. Son kontrol

- Masaüstü ve mobil ana sayfada CSS/JS bozukluğu yok.
- Production logunda yeni PHP fatal/uncaught exception yok.
- Şifre sıfırlama maili hosting üzerinde gerçek bir e-posta ile test edilmiş.
- Kullanıcı kayıtları ancak bu noktadan sonra açılmış.
