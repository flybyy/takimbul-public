# TakımBul v10.1.1 — Gerçek Kullanıcı Açılış Kontrolü

## 1. Yedek

- Canlı MySQL veritabanının hosting panelinden tam yedeğini al.
- `config/app.php` dosyasını koru.
- `public/uploads/` klasörünü koru.

## 2. Dosya güncelleme

- v10.1.1 ZIP dosyasını mevcut v10.1 dosyalarının üstüne yükle.
- `config/app.php` ve `public/uploads/` üzerine yazma/silme yapma.

## 3. Şema audit

```bash
php scripts/production-repair.php
```

Eksik tablo/kolon/index/ENUM varsa script yalnız raporlar; değişiklik yapmaz.

## 4. Güvenli repair

```bash
php scripts/production-repair.php --apply
```

Sonuç `DB runtime şeması [OK]` olmadan devam etme.

## 5. Launch gate

```bash
php scripts/launch-check.php
```

Kritik `[!!]` sayısı 0 olmalı. Search Console veya aktif reklam kampanyası gibi operasyonel uyarılar ayrı değerlendirilebilir; DB, asset, admin ve runtime şeması mutlaka `[OK]` olmalı.

## 6. Transactional production smoke

```bash
php scripts/production-smoke.php
```

Şunların tamamı `[OK]` olmalı:
- DB bağlantısı
- Runtime şema
- Kritik modül read sorguları
- Kayıt + profil write
- Müsaitlik write
- Takım arama profili write
- Amatör futbolcu ilanı + kariyer geçmişi write
- Reklam placement write
- Rollback

Smoke script gerçek test hesabı bırakmaz; transaction rollback yapar.

## 10. Açılış kararı

Gerçek kullanıcı kaydı yalnız şu durumda açılır:
- production-repair audit OK
- production-repair --apply OK
- launch-check kritik hata 0
- production-smoke PASS
- gerçek kayıt/giriş tarayıcı testi PASS
- `/musait-oyuncular` ve `/amator-futbolcular` HTTP 200
- admin ayrı oturumda çalışıyor
- telefon public sayfalarda görünmüyor
