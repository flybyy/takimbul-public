# Security Policy

## Supported code

Public repository güncel uygulama kaynak kodunun portföy/akademik kopyasını içerir. Production credentials ve kullanıcı verileri repository dışında tutulur.

## Güvenlik açığı bildirimi

Bir güvenlik açığı fark edersen exploit ayrıntılarını public issue olarak yayınlama.

Bunun yerine proje sahibiyle özel bir kanal üzerinden iletişim kur ve mümkünse şu bilgileri paylaş:

- etkilenen endpoint / bileşen,
- tekrar üretme adımları,
- beklenen ve gerçekleşen davranış,
- olası etki,
- önerilen düzeltme (varsa).

Lütfen gerçek kullanıcı verisine erişmeye, veri değiştirmeye veya servis sürekliliğini etkilemeye çalışma.
